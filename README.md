# AA 18 - Tateti

Juego de tateti para dos jugadores hecho con HTML, CSS y JavaScript.

## Cómo jugar

1. Abrir `index.html` en el navegador.
2. Empieza X; los jugadores se turnan haciendo click en las celdas.
3. Gana el primero que complete una fila, columna o diagonal. Si se llena el tablero sin ganador, es empate.

## Funcionalidades

- Detección de ganador y empate.
- Resaltado de la línea ganadora.
- Marcador de victorias de X, O y empates.
- Botón para jugar una nueva partida y botón para reiniciar el marcador.
